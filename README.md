# IRON WAR

Стратегія в реальному часі на випадково згенерованій карті. Ти — сині (ліворуч), ШІ — червоні. Знищ штаб ворога (3000 HP).

**Запуск:** відкрий `index.html` у браузері (F11 — повний екран). Нічого встановлювати не треба.

- Гроші капають +45/с. Панель внизу: клік по картці або клавіші `1–9`.
- CAB / ROCKET / NUKE BOMB: вибери картку, потім клікни по карті. ПКМ / Esc — скасувати.
- CAB скидає найближчий свій літак, ROCKET летить зі штабу, NUKE — приліт за 3 с, б'є всіх, і своїх.
- Танки ходять лише по суші й обходять море/озера. Літаки, МІ-24 та шахіди літають над усім.
- Свої звуки: папка `sounds/`, див. `sounds/README.md`.
- `P` / `Esc` — пауза, `M` — вимкнути звук (є й кнопка 🔊 угорі). «Нова карта» генерує нову місцевість.

## GitHub Pages
Залий папку в репозиторій → Settings → Pages → Source: **GitHub Actions**. Воркфлоу `.github/workflows/pages.yml` опублікує гру.

## Windows .exe
Воркфлоу `build-exe.yml` збирає гру в exe (Electron) з твоєю іконкою. Після пуша в `main`: **Actions → build-exe → Artifacts → Iron-War-Windows**.
- `Iron-War.exe` — одним файлом (portable). Свої звуки клади в папку `sounds/` **поруч з exe**.
- `Iron War-1.0.0-win.zip` — розпакована папка з `Iron War.exe` і готовою `sounds/`.
- F11 — повний екран. Локально: `npm install && npm start` (запуск) або `npm run dist` (збірка).
