# Звуки Iron War

Поклади свої файли сюди, у цю папку (`sounds/`), з **точними іменами** з таблиці.
Формати: `.mp3`, `.ogg` або `.wav` (гра шукає саме в такому порядку). Імена — малими літерами.

Якщо файлу немає, гра грає вбудований синтезований звук. Можна замінити лише частину звуків.

## Разові звуки (грають при події)

| Файл | Коли грає | Порада |
|---|---|---|
| `tank_shot` | постріл танка | 0.5–1 с, глухий гучний |
| `gun_shot` | кулеметна черга літаків і Мі-24, постріл турелі штабу | дуже короткий (0.05–0.15 с), бо повторюється часто |
| `explosion_small` | вибух ракети, КАБу, шахіда, загибель техніки | 0.5–1.5 с |
| `explosion_big` | вибух радіусом від 120 px (ядерний вибух) | 2–4 с, низький |
| `rocket_launch` | пуск ракети зі штабу | 1–1.5 с |
| `bomb_whistle` | скидання КАБу | 1–1.5 с |
| `shahid_whistle` | шахід заходить в атаку (за ~230 px до цілі) | 1–1.5 с |
| `rocket_whistle` | ракета на фінальному підльоті (за ~320 px до цілі) | 0.8–1 с |
| `nuke_whistle` | ядерна ракета: запуск, свист до самого удару | рівно ~3 с |
| `nuke_beep` | сигнал щосекунди під час 3-секундного відліку ядерки | 0.2 с |
| `nuke_blast` | момент ядерного удару (грає разом з `explosion_big`) | 3–5 с |
| `ui_click` | купівля юніта на панелі | 0.05–0.2 с |

## Циклічні звуки (крутяться, поки такі юніти є на полі)

Робити безшовно, 3–10 с. Гучність росте з кількістю юнітів. Коли їх немає, звук зупиняється.

| Файл | Для чого |
|---|---|
| `engine_tank` | двигун танків |
| `engine_jet` | МіГ-23, МіГ-25, F16 |
| `engine_heli` | Мі-24 |
| `engine_shahid` | шахіди |

## Важливо
- Відкривай гру через `index.html` двічі клацнувши або через сайт. Звуки вмикаються після першого кліку (правило браузера).
- Звуки лежать поруч з `index.html`: `iron-war/sounds/tank_shot.wav` тощо.
- Кнопка 🔊 або клавіша `M` вимикає все, і ваші файли теж.
